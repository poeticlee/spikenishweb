# Image credits

This website uses a mix of **openly licensed photos** and **photos supplied by the business
owner**.

- **Owner-supplied photos** need no attribution — replace more of the stock images with your
  own shop, product and training photos whenever you can. Original photos also rank better
  on Google.
- **Openly licensed photos** (Wikimedia Commons / Openverse, CC BY and CC BY-SA licences)
  require attribution — the list below must be kept **while those files are still used**.

Drop a replacement file into this folder using the same name and the website updates itself.
